Changelog

Local release 1.65.0 is ready for review and pending manual publication. The official Chrome Web Store listing showed 1.26.2, updated 29 August, when checked on 10 September 2026. Add to Chrome follows the store release; it does not install unpublished local changes. The full engineering log is in Documentation → Changelog.

  1. 1.65.010 Sep 2026 · local · pending publication
    Faster refresh, clearer settings and useful support.
    • Gmail refresh reuses unchanged snapshots and shows actionable synchronization status. Full-page navigation and button layouts are more consistent.
    • Settings and Help & feedback gain clearer controls, recoverable drafts and better diagnostic context.
    • The comparison now covers twelve relevant tools, keeps Checker Plus as the replacement baseline, and defaults to Overall descending. Every rating has reasons and official sources; desktop fit, phone access and background operation are explained separately.
    • Roadmap and voting controls are removed. Documentation describes the features and limits that are actually implemented.
    • The redesigned support page separates likes from donations. The anonymous public like counter starts a new zero-based count when its supporting service is deployed; cleanup activity and donation clicks do not count as likes.
    Website and counter-service changes also await manual deployment. This is not a claim that the store or live website already serves this release.
