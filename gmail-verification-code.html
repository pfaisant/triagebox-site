How Copy code actually runs

Add to Chrome installs this product. These are the steps on a signed-in Gmail account you are authorised to use.

  1. Install and connect Gmail. Desktop Chrome or another Chromium browser. Google OAuth is still unverified, so the first run shows Google’s warning screen. No TriageBox account.
  2. Leave the code email in the queue. TriageBox looks at the subject for wording like verification code, sign-in code, one-time code, OTP, and the common French, Spanish, German, and Italian equivalents.
  3. One candidate, or nothing. A single 4–8 digit number that is not a year, or one mixed letter-and-digit token. Two numbers means no button from the subject.
  4. Copy code. The clipboard gets the characters only. Paste it yourself into the site that asked. If you did not request the code, do not enter it.

Limits, stated

What this page does not claim

  • It does not read SMS, WhatsApp, or an authenticator app.
  • It does not type the code into the site that asked, and it does not bypass 2FA.
  • It does not invent a code. Several numbers in the subject means no Copy code from the subject.
  • It does not copy a code from Sent mail you wrote. That code is someone else’s.
  • It does not appear instantly when the code is only in the body. That waits until the message is read and the same characters are found there.
  • It does not decide the mail is safe. A code you did not request should not be entered. Sender checks are Gmail phishing checker.
  • It does not list unanswered sent mail. That is Gmail waiting for reply.
  • It does not unsubscribe senders. That is bulk unsubscribe Gmail.
  • It does not delete old mail. That is delete old emails in Gmail.
  • It does not run on your phone.
  • It does not send the code through a TriageBox server.
  • It is not for anyone else’s mailbox.

Quick answers

Gmail verification code

How do I copy a Gmail verification code without opening the email?

TriageBox 1.57 is a Chrome extension. When a message in your own Gmail is a sign-in or verification code and the subject already contains exactly one code, the card shows that code large, with a Copy code button. Copy strips spaces and dashes. This does not read SMS, and it does not type the code into another site for you.

Does copying the code need an AI key?

No, when the code is already in the subject and there is exactly one candidate: a single 4 to 8 digit number that is not a year, or one mixed letter-and-digit token. If the subject only says a code exists, TriageBox waits until that message is read and the same characters are found in the body. It will not invent a code it did not find. A wrong clipboard guess is worse than no button, so several numbers in the subject means no Copy code from the subject.

Is this the Gmail phishing checker?

No. The phishing checker reads Gmail’s SPF, DKIM and DMARC plus reply path and attachments on the card you are looking at. This page is only the copy-the-code chore. A code you did not request is still a reason not to enter it, and to change that account’s password. Use Gmail phishing checker for that job, Gmail waiting for reply for unanswered sent mail, bulk unsubscribe Gmail to stop lists, and delete old emails in Gmail to clear by age.

Does my mail go through a TriageBox server?

No. There is no developer-operated backend. Processing runs in your browser; Gmail data is not sent to the publisher. The code is copied to your clipboard on this computer.
