How Until sender replies actually runs

  1. Install and connect Gmail. Desktop Chrome. No TriageBox account.
  2. Open Snooze on a real thread. Time presets are still there. Under them: Until sender replies — “wakes on answer · 7d max”.
  3. It leaves the queue. The card’s time slot reads when sender replies while it is snoozed. Any new message on that thread wakes it; otherwise the seven-day backstop does.
  4. Or pick a clock instead. This option does not replace time snooze. Use Waiting for reply when the job is a list of your unanswered sent mail.

Limits, stated

What this page does not claim

  • It does not replace Gmail’s time snooze. Those presets are still on the menu.
  • It does not wait forever. Seven days is the backstop if nobody answers.
  • It does not only wake on the original From. Any new message on the thread wakes it.
  • It does not list unanswered sent mail. That is Gmail waiting for reply.
  • It does not nudge the other person or track opens.
  • It does not work on news or feed cards — only real Gmail threads.
  • It does not unsubscribe or delete mail. Those are bulk unsubscribe and delete old emails.
  • It does not run on your phone. Gmail’s own time snooze is what you have there.
  • It does not send mail through a TriageBox server.
  • It is not for anyone else’s mailbox.

Quick answers

Snooze until the sender replies

Can I snooze a Gmail email until the sender replies?

Gmail’s own snooze is time-based only — tonight, tomorrow, next week. TriageBox 1.57 is a Chrome extension with Until sender replies on the snooze menu: the thread leaves the queue until someone answers, or for 7 days at most. No API key. This is not the Waiting tab, which lists sent mail nobody answered.

Who counts as a reply?

Any new message on that thread wakes it. The backstop is seven days if nobody writes. The snoozed list shows when sender replies on the card. Feed or news items cannot use this option — only real Gmail threads.

Is this the same as waiting for reply?

No. Waiting for reply is a list of sent threads where you wrote last and nobody answered for 2+ days. Snooze until reply hides an inbound thread you are done with for now, and brings it back when someone answers. Use Gmail waiting for reply for the outbound list.

Does my mail go through a TriageBox server?

No. There is no developer-operated backend. Processing runs in your browser; Gmail data is not sent to the publisher.
