# triagebox-site

Public marketing / policy pages for **TriageBox AI Gmail Checker**, the Chrome extension for focused Gmail triage.

- **Canonical site:** https://triagebox.pfa87.cc/
- **Role of this repo:** GitHub Pages fallback when the primary host is unreachable. Canonical URLs on the pages still point at `triagebox.pfa87.cc`.
- **Chrome Web Store:** [TriageBox: AI Checker for Gmail](https://chromewebstore.google.com/detail/triagebox-ai-checker-for/fdkbolcjccjkgadblcfnbnlibaiaellj)

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Product homepage (OAuth branding name: TriageBox AI Gmail Checker) |
| `privacy.html` | Privacy policy |
| `terms.html` | Terms of service |
| `donate.html` | Optional support / donate |
| `site.css` / `analytics.js` | Shared styles and consent-controlled analytics |

The private extension source lives in [`pfaisant/triageBox`](https://github.com/pfaisant/triageBox).
