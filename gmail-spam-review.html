Limits, stated

What this page does not claim

  • It does not replace Gmail’s Spam folder. That still works, for free, with no extension.
  • Delete entire folder does not ask which threads — everything in spam goes to Trash after the armed confirm.
  • It does not delete forever on that click. Trash holds mail for about 30 days; then Google removes it.
  • A large folder may be capped; run Delete entire folder again to continue.
  • It does not check SPF/DKIM on the card. That is Gmail phishing checker.
  • It does not unsubscribe senders. That is bulk unsubscribe Gmail.
  • It does not clear old inbox mail by age. That is delete old emails.
  • It does not run on your phone.
  • It does not send mail through a TriageBox server.
  • It is not for anyone else’s mailbox.

Quick answers

Gmail spam review

How do I review and empty Gmail spam without opening every message?

Gmail’s Spam folder lets you open messages one by one, or select all and delete. TriageBox 1.65 is a Chrome extension with a Spam tab: Review & clean up opens a full-page spam pass so the popup can close while it runs, and Delete entire folder moves every spam thread to Trash after a second confirmation. Rescued mail leaves spam; deleted mail sits in Trash for about 30 days. This is not the phishing checker.

Does Delete entire folder skip review?

Yes. That button deletes every spam thread, reviewed or not. It is armed first and fires on a confirming second click. Prefer Review & clean up when you may have false positives. A long run can be capped; run again to continue. Failures are reported in the toast.

Is this the Gmail phishing checker?

No. The phishing checker reads SPF, DKIM, DMARC, reply path and attachments on a card you are looking at. Spam review is the Spam folder. Use Gmail phishing checker for sender checks, bulk unsubscribe to stop lists, and delete old emails for age cleanup.

Does my mail go through a TriageBox server?

No. There is no developer-operated backend. Processing runs in your browser; Gmail data is not sent to the publisher.
