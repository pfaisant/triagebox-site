How stopping promotions actually runs

  1. Install and connect Gmail. Desktop Chrome. No TriageBox account.
  2. Bulk sweep → Categories & age. Pick Promotions (or Social / Updates / Forums). One Gmail query. Live exact count before archive or delete. Scoped like inbox mode; can Count all mail instead. Cap marked as 20,000+ when capped.

  4. Unsubscribe on cards. RFC 8058 one-click when present (no confirmation from the sender). Preference or mailto shown for manual review. AI link extract is last resort. Stop promotional emails in Gmail

How do I stop promotional emails in Gmail without opening every message?

Gmail’s Promotions tab already sorts marketing mail. TriageBox 1.65 is a Chrome extension: Bulk sweep can target Promotions (also Social, Updates, or Forums) with one Gmail query, show a live exact count, then archive or delete. Cap is marked 20,000+ when capped. You can Count all mail instead. Unsubscribe on cards uses RFC 8058 one-click when present. No AI key for core unsub or sweep. No TriageBox mailbox server. Desktop Chrome only.

What does Normal mail only do?

The Normal mail only toggle (mail icon before Triage) hides newsletters, offers, social/forum mail and messages scored below 45 from the displayed list. It does not archive or delete — it filters what you see. Turn it off to see the full pile again.

Is this the same as bulk unsubscribe Gmail?

No. Bulk unsubscribe is per exact sender, then a leftover sweep. This page is the promotional angle: category/age bulk sweep, Normal mail only, and Unsubscribe on cards. Use delete old emails for age-first cleanup and spam review for the Spam folder.

Does my mail go through a TriageBox server?

No. There is no developer-operated backend. Processing runs in your browser; Gmail data is not sent to the publisher.
